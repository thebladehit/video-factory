## 1. Мета

Готове відео (з бібліотеки або з ОС) або проєкт з редактора озвучується кількома мовами з субтитрами в студії озвучки, без відкриття редактора, і рендериться в N мовних MP4. Підтримуються обидва сценарії порівну:
- **дубляж** — відео з мовленням: розпізнати → переклад → озвучка N мовами; оригінальний голос прибрати або приглушити;
- **озвучка німого відео** — текст пише/вставляє користувач → переклад → озвучка N мовами.

### Рішення власника (з обговорення)
| Питання | Рішення |
|---|---|
| Різна довжина мов | **Відео підлаштовується під озвучку, а не навпаки.** Швидкість озвучки не змінюється ніколи (жодного `atempo` на голосі). Спершу генерується озвучка мови, потім під неї рахується час кадрів; кожна мовна версія має власну тривалість. **Замінює** варіант C базової специфікації (§2, §5.2: `atempo` ±15 %) |
| Як відео підганяється | Шматок відео сегмента змінює темп у межах ×0,8…×1,25; якщо озвучка все одно довша — стоп-кадр в кінці шматка; якщо коротша — хвіст шматка обрізається |
| Модель мов | Варіант A: межі сегментів у `TimelineDoc`, тексти/озвучки мов у БД, чиста функція `localize(doc, lines, lang) → TimelineDoc` — спільна для прев'ю й рендеру. «Відокремити мову» матеріалізує результат |
| Мітки слів | OpenAI `whisper-1` по згенерованому аудіо + зіставлення зі словами тексту. Без ключа OpenAI — оцінка за довжиною слів і паузами (`silencedetect`) з попередженням у UI |
| Оригінальний звук | Перемикач: «Замінити» (0 %) або «Приглушити» (рівень X %, під голосом — ще нижче, з плавними переходами; детерміновано за часом сегментів) |
| Субтитри | 4 пресети + редактор стилю (шрифт із 6 вбудованих, розмір, кольори, обведення, плашка, позиція, слів у рядку, регістр), збережені стилі в `caption_styles` |
| Студія й редактор | Студія — єдине місце роботи з текстом і голосом (`/voice/$id`). Редактор показує доріжки озвучки/субтитрів у режимі перегляду мови, рендерить мови, «Відокремити мову», кнопка «Озвучка» |

## 2. Ядро: сегменти й `localize` (`packages/timeline`)

### 2.1 Схема (`packages/shared`, лишається `schemaVersion: 1`, лише необов'язкові поля)
- `TimelineDoc.segments?: { id, start, end }[]` — відрізки **базового** таймлайну; впорядковані, не перекриваються, ≥ 1 кадр, у межах `[0, docDuration]`. Проміжки між сегментами не змінюються (темп 1).
- `MediaClip` і `AudioClip` + `speed?: number` (0,8–1,25; за замовчуванням 1) і `hold?: number` (секунди стоп-кадру/тиші в кінці; 0). Зі джерела береться `(duration − hold) × speed` с. Поля з'являються лише в документах, які породжує `localize`, і у «відокремлених» мовах; операції редактора їх зберігають.
- `AudioClip` + `envelope?: { t: number; gain: number }[]` — кусково-лінійний множник гучності (`t` — секунди від початку кліпу). Для ducking.
- `CaptionClip` (вже є: `id, audioClipId, transcriptId, styleId`) — без змін.
- `evaluate` і `audioPlan` враховують `speed`/`hold`: `sourceTime = in + min(local, duration − hold) × speed`; `AudioItem` + `speed`, `hold`, `envelope`.

### 2.2 Операції над сегментами (чисті `doc → doc`, у редакторі й студії)
`splitSegmentAt(t)` (розрізати сегмент під плейхедом або створити новий на вільному місці), `mergeSegments(a, b)`, `setSegmentBounds(id, start, end)` (з межами сусідів і снепінгом до країв кліпів), `deleteSegment(id)`, `segmentsFromText(paragraphs, duration)` (рівномірне розбиття тривалості під абзаци), `segmentsFromSpeech(speechSegments, duration)` (див. 4.2).

### 2.3 `localize(doc, lines, lang, opts) → { doc, map }`
Вхід: базовий документ, рядки озвучки мови `{ segmentId, audioAssetId, durationSec, transcriptId }` (лише `ready`), налаштування мови (стиль субтитрів, увімкнені субтитри) і оригінального звуку. Вихід: звичайний `TimelineDoc` (без `segments`) + карта часу.

1. **Цільова довжина сегмента.** Сегмент із готовою озвучкою V: `T = LEAD + V + TAIL` (`LEAD = 0,15 с`, `TAIL = 0,35 с`; константи). Сегмент без озвучки цієї мови: `T = D` (базова довжина). Швидкість `s = clamp(D / T, 0,8, 1,25)`; використано джерела `U = min(D, T × s)`; стоп-кадр `H = max(0, T − D / s)`; обрізано `D − U` (хвіст).
2. **Карта часу** `map(tBase) → tLang` — кусково-лінійна: у межах сегмента `segStartLang + (tBase − segStart) / s` до `segStart + U`; проміжки між сегментами — зсув на накопичену різницю. Округлення до кадру.
3. **Візуальні кліпи** (і зв'язаний «Звук відео», роль `original`) розрізаються на межах сегментів і в точці `segStart + U`; шматки в обрізаному хвості видаляються; решта отримують `start/duration` через карту, `speed = s` всередині сегмента; кліпи, що закінчуються на кінці використаної частини сегмента, отримують `hold = H`. Параметри ефектів шматків перераховуються так, щоб закон у кожній точці збігався з базовим (`kenburns`/`zoom` — значення на межах шматка; `fade` in — лише першому шматку, out — останньому; `xfade` лишається, якщо перекриття всередині одного сегмента, інакше обрізається до межі).
4. **Музика й sfx** не перераховуються: позиції як є, обрізаються по новій тривалості документа.
5. **Озвучка**: доріжка `voiceover` з `language` — кліп на `segStartLang + LEAD`, `duration = V`, `speed = 1`.
6. **Оригінальний звук** (кліпи ролі `original` і `volume` відео-кліпів): `replace` → гучність 0; `duck` → множник `level` (за замовчуванням 0,25) і `envelope`, що опускається до `duckLevel` (0,08) під кліпами озвучки з рампою 0,2 с.
7. **Субтитри**: доріжка `captions` з `language` — `CaptionClip` на кожен кліп озвучки (`transcriptId`, `styleId`), якщо субтитри мови увімкнені.

Сегмент без озвучки в мові, де інші сегменти озвучені, — нормальний випадок (пауза). Мова без жодної готової озвучки → `localize` повертає документ з темпом 1 (тобто базовий).

### 2.4 Узгодженість прев'ю й рендеру
- Прев'ю мови X: `drawFrame(evaluate(localize(...).doc, t))` + аудіо з `audioPlan` + JASSUB з ASS з того самого документа. Рендер мови X: `compileFfmpeg(localize(...).doc)` + той самий ASS. Тривалість і таймінг слів збігаються за конструкцією.

## 3. Субтитри (`packages/captions`, новий пакет; чистий TS)

### 3.1 Стиль
```ts
type CaptionStyle = {
  font: FontId;                 // один із 6 вбудованих
  size: number;                 // % висоти кадру (3–12)
  color: string; activeColor: string;     // #RRGGBB
  outline: { color: string; width: number };  // px при 1080p
  shadow: number;
  box: { enabled: boolean; color: string; opacity: number };   // плашка (BorderStyle=3)
  position: { align: 'bottom' | 'middle' | 'top'; marginY: number };   // % висоти
  maxWordsPerLine: number;      // 1–8
  maxLines: 1 | 2;
  uppercase: boolean;
  animation: 'none' | 'highlight' | 'pop' | 'karaoke';
};
```
- **Пресети** (константи `preset:…`, не рядки БД): «Шортс — підсвітка слова» (великі, середина кадру, верхній регістр, `highlight`), «Pop по слову» (по 1–2 слова, `pop`), «Караоке» (`\k`-заливка), «Класичні рядки» (16:9, низ, плашка, `none`).
- Шрифти (OFL, з кирилицею й латиницею): Montserrat, Inter, Oswald, Rubik, Roboto Slab, Unbounded — файли TTF у `packages/captions/fonts`, копіюються в образ API (для `fontsdir` у ffmpeg) і віддаються вебу як статичні файли для JASSUB. Мови з іншими писемностями (CJK, арабська, деванагарі…) — озвучка працює, субтитри для них вимкнені з поясненням (поза обсягом).

### 3.2 Генератор
- `layoutWords(words, style) → Page[]` — групування в «сторінки» (1–2 рядки по ≤ `maxWordsPerLine` слів), розрив на паузі > 0,5 с, на кінці речення або при перевищенні довжини рядка (оцінка ширини за середньою шириною гліфа шрифту; перенос рядків явний, `\N`, `WrapStyle: 2`).
- `toAss(doc, transcripts, styles, { width, height }) → string` — `PlayResX/Y` = розмір кадру; стиль → `[V4+ Styles]`; кожна сторінка — `Dialogue`; анімації: `highlight` — активне слово окремим кольором (по події на слово), `pop` — `\t(\fscx\fscy)` 100→115→100 за 120 мс, `karaoke` — `\kf`. Час слова на таймлайні = `clip.start + (word.startMs/1000 − clip.in)`; слова поза кліпом відкидаються.
- `toSrt` / `toVtt` з тих самих сторінок (для завантаження; публікація — підпроєкт 5).

### 3.3 Прев'ю — JASSUB
- `jassub` (libass у WASM) — прозорий canvas поверх canvas-прев'ю, той самий розмір і DPR; `subContent` = `toAss(...)`, `fonts` — URL вбудованих шрифтів; час — з годинника `PreviewEngine` (`setCurrentTime` на кожному кадрі/seek). Оновлення ASS при зміні стилю/тексту — з debounce 300 мс.
- **Спайк на початку реалізації:** JASSUB без `<video>`, з нашим годинником і поверх canvas (режим `canvas` / ручний рендер), у воркері; Vite-збірка воркера й WASM. Запасний варіант — рендер ASS у прихований canvas через `manualRender` на кожен кадр.

### 3.4 Рендер
`compileFfmpeg` для мови: ASS пишеться у файл поруч зі скриптом графа, останнім фільтром відео-ланцюжка, **після** повернення до розміру виходу (зокрема після масштабування 2× → 1× і в `draft`) — `subtitles=f=…:fontsdir=…`; `PlayResX/Y` = розмір документа, libass сам масштабує координати й розміри до розміру виходу.

## 4. Мітки й розпізнавання

### 4.1 Мітки слів для озвучки (`packages/ai` + `packages/captions`)
- **З ключем OpenAI:** згенероване аудіо → `whisper-1` (`language`, `prompt` = текст рядка) → слова з мітками → `alignWords(scriptText, sttWords)`: токенізація (нижній регістр, без пунктуації, нормалізація апострофів/дефісів), вирівнювання DP (Levenshtein на токенах); слова тексту отримують мітки зіставлених, незіставлені — інтерполяцію між сусідами. Результат — **слова тексту** (з пунктуацією) з часом аудіо; `timing: 'aligned'`.
- **Без ключа OpenAI:** `estimateWords(text, durationMs, speechIntervals)` — `ffmpeg silencedetect` (−35 dB, 0,2 с) дає інтервали мовлення; слова розподіляються пропорційно кількості символів у межах інтервалів; `timing: 'estimated'`, у студії — попередження «Мітки слів приблизні: додайте ключ OpenAI».

### 4.2 Розпізнавання оригіналу (дубляж)
- Джерело — мікс звуку ролі `original` базового документа (аудіо-рендер через `compileFfmpeg` у режимі «лише звук»: моно 16 кГц, Opus 32 кбіт/с у WebM — ≈ 15 МБ/год). Довше 90 хв → частини по 60 хв з перекриттям 5 с, склеювання за мітками.
- `whisper-1` → сегменти й слова; або `gemini-3.8-flash` → сегменти за Zod-схемою `{ start, end, text }[]` (без слів).
- `segmentsFromSpeech`: сегменти STT об'єднуються в речення/фрази 2–15 с (розрив на кінці речення або паузі > 0,7 с); межі сегментів проєкту = початки фраз (перший сегмент від 0 до першої фрази — без тексту; останній — до кінця відео). Текст фраз → рядки базової мови з `text_origin: 'stt'`. Мова визначається автоматично (whisper) або вибирається вручну.
- Повторне розпізнавання замінює сегменти й тексти базової мови лише після підтвердження («Наявні сегменти й тексти буде замінено»).

## 5. Дані (міграція 0005)

**`voice_lines`** — рядок «сегмент × мова»; унікальний `(project_id, segment_id, language)`:
`id`, `user_id`, `project_id` (cascade), `segment_id text`, `language`, `text`, `text_origin` (`manual|stt|translated`), `source_hash text null` (хеш базового тексту на момент перекладу), `voice jsonb null` (`{ model, voiceId, instructions? }`, з яким озвучено), `audio_asset_id uuid null` (`on delete set null`), `transcript_id uuid null`, `duration_ms int null`, `voiced_hash text null` (хеш `text + voice` на момент озвучки), `status` (`empty|queued|running|ready|failed`), `job_id`, `error`, `updated_at`.
- Рядки сегментів, яких немає в документі, ігноруються (undo повертає сегмент разом з озвучкою) і видаляються разом із проєктом.
- **Застарілий** — обчислюваний стан: `voiced_hash` ≠ поточному (текст або голос змінено після озвучки) або `source_hash` ≠ хешу поточного базового тексту (переклад застарів). Автоматично нічого не перегенеровується; у студії — жовта позначка й «Оновити».

**`transcripts`**: `id`, `user_id`, `asset_id` (cascade), `language`, `source` (`tts|stt`), `text`, `words jsonb` (`[{ text, startMs, endMs }]`), `timing` (`aligned|estimated|stt`), `created_at`.

**`caption_styles`**: `id`, `user_id`, `name`, `style jsonb`, `created_at`, `updated_at`.

**`project_language_timelines`**: `project_id` (cascade), `language`, `timeline jsonb`, `timeline_version int`, `created_at`, `updated_at`; PK `(project_id, language)`.

**`projects`** + `voice jsonb not null default '{}'`:
```
{ languages: { [lang]: { voice?: { model, voiceId, instructions? }, captions: { enabled: boolean, styleId: string } } },
  original: { mode: 'replace' | 'duck', level: number, duckLevel: number } }
```
Наявні `base_language` і `languages[]` використовуються як є (порядок мов = порядок у UI).

**`renders`** + `subtitles text null` (ASS, згенерований на старті рендеру — знімок разом із `timeline_snapshot`); `language` (вже є) заповнюється для рендерів мов.

**`user_settings`** + `voices jsonb not null default '{}'` — голос за замовчуванням для кожної мови (`{ [lang]: { model, voiceId } }`). Моделі `tts`/`stt` — наявні `defaults.tts`/`defaults.stt`; переклад — `defaults.text`.

**Мови** — конфіг `packages/shared/src/languages.ts`: код, назва українською, писемність, чи є шрифти для субтитрів. Набір: uk, en, es, de, fr, it, pt, pl, nl, cs, ro, tr, sv, ru, kk (латиниця/кирилиця — субтитри доступні). Нова мова = рядок у конфігу; мова з іншою писемністю додається з `captions: false` (лише озвучка).

**Озвучка** — звичайний asset (`kind='audio'`, `source='generated'`, `language`, теги: мова, «озвучка», назва проєкту), видно в бібліотеці; ключ `u/{userId}/assets/{assetId}/original.wav`. Запис у `generations` (`capability='tts'`, `cost_estimate`). Розпізнавання — `generations` з `capability='stt'`.

## 6. AI і задачі

### 6.1 Адаптери (`packages/ai`)
- `TTS.synthesize({ text, voiceId, language, instructions?, signal })` → WAV. OpenAI: `audio.speech` (`response_format: 'wav'`); Google: `generateContent` з `responseModalities: ['AUDIO']`, `speechConfig.voiceConfig` і стилем, PCM/WAV → WAV-заголовок. Вхід обмежено 1500 символами на рядок (більше — `VALIDATION`, «розділіть сегмент»).
- `STT.transcribe({ audio, mime, language?, prompt?, signal })` → `{ text, language?, segments: {start,end,text}[], words?: Word[] }`. OpenAI `whisper-1` (`verbose_json`, слова й сегменти); Google — `generateObject` за схемою сегментів.
- Помилки — наявні `providers/errors.ts` (429/тимчасові — ретрай із backoff; контент-політика — без ретраїв).
- **FakeProvider:** TTS — WAV тиші (за бажанням — тон 440 Гц, щоб чути) тривалістю 0,4 с на слово + точні мітки; STT — детерміновані сегменти з тексту-заглушки або (для аудіо, що створив fake TTS) — слова з тими самими мітками; переклад — fake text з префіксом мови `[en] …`.

### 6.2 Задачі
| Задача | Payload | Конкурентність | Що робить |
|---|---|---|---|
| `voice.transcribe` | `{ projectId, language? }` | 2 | мікс `original` → STT → `segmentsFromSpeech` → збереження сегментів у документі (сервер оновлює `timeline` з інкрементом версії; відкритий редактор отримає наявну модалку конфлікту, студія перечитує проєкт) + рядки базової мови. Немає доріжки `original` з аудіо → `VALIDATION` «У відео немає звуку» |
| `voice.translate` | `{ projectId, language, segmentIds? }` | 2 | `TextGen.generateObject` — усі сегменти одним запитом (контекст для узгодженості термінів; довгі проєкти — порціями по 60 сегментів з попереднім контекстом); промпт: природна мова для озвучки, без пояснень, довжина близька до оригіналу; заповнює `text`, `text_origin='translated'`, `source_hash` |
| `voice.synthesize` | `{ lineId }` | 3 | TTS → asset (`ready` одразу після `asset.process`-метаданих) → мітки (4.1) → `transcripts` → `duration_ms`, `voiced_hash`, `ready`. Ідемпотентно: якщо `voiced_hash` збігається й asset `ready` — нічого |
- Масові дії студії («Озвучити все», «Перекласти все») ставлять задачі по рядках; прогрес — наявний `jobs.feed`.
- Перед «Озвучити все» — оцінка вартості: символи → хвилини (≈ 15 символів/с) × ціна моделі + `whisper-1`.

## 7. API

| Процедура | Поведінка |
|---|---|
| `voice.get({ projectId })` | сегменти (з документа) × мови: рядки зі статусом, «застарілий», URL аудіо; налаштування `voice`; транскрипти (слова) для прев'ю субтитрів; стилі; вартість-оцінка |
| `voice.createFromAsset({ assetId })` | проєкт «{назва} — озвучка» формату за орієнтацією відео (квадратне → 9:16 з `contain`), один кліп на весь файл + зв'язаний «Звук відео»; повертає `projectId` |
| `voice.setLanguages({ projectId, base, languages })` | мови проєкту; зміна базової мови не чіпає тексти |
| `voice.setVoice({ projectId, language, voice })`, `voice.setOriginal({ projectId, original })`, `voice.setCaptions({ projectId, language, enabled, styleId })` | налаштування `projects.voice` |
| `voice.setText({ projectId, segmentId, language, text })` | ручний текст (`text_origin='manual'`) |
| `voice.transcribe`, `voice.translate`, `voice.synthesize({ projectId, language?, segmentIds? })` | ставлять задачі (6.2); `synthesize` без `segmentIds` — усі не готові або застарілі рядки мов |
| `voice.preview({ model, voiceId, language })` | зразок голосу (фраза мовою), кеш `u/{userId}/voice-samples/{model}/{voiceId}/{lang}.wav` |
| `voice.localized({ projectId, language })` | `localize` на сервері → `{ timeline, subtitles (ASS), assets }` — для прев'ю в редакторі/студії (той самий код, що й у рендері) |
| `voice.separate({ projectId, language })` / `voice.unseparate(...)` | записати / видалити `project_language_timelines` |
| `projects.get/save` для відокремленої мови | `projects.get({ id, language })` і `projects.save({ id, language, timeline, baseVersion })` — працюють з рядком `project_language_timelines` (та сама оптимістична версія) |
| `captionStyles.list / create / update / delete` | збережені стилі + пресети |
| `renders.start({ projectId, preset, version, language? })` | з `language`: відокремлена мова → її документ; інакше `localize` (лише рядки `ready`; незавершені → `VALIDATION` «Є неозвучені/застарілі сегменти» з переліком, рендер можна підтвердити «все одно»); у знімок — документ і ASS |
| `renders.startAll({ projectId, preset, languages })` | по рендеру на мову |

Сегменти редагуються як частина документа (`projects.save`), тексти — через `voice.*`.

## 8. Рендер (`packages/render`)
- `speed` у відео: `setpts=(PTS-STARTPTS)/speed`, на вході `-t` = використана частина джерела; `hold`: `tpad=stop_mode=clone:stop_duration=H`. Фото — `speed`/`hold` не впливають (просто довший показ).
- `speed` в аудіо (`original`): `atempo` (0,8–1,25 — один фільтр); `hold` — `apad`. Голос озвучки ніколи не отримує `speed ≠ 1`.
- `envelope`: `volume='…':eval=frame` з кусково-лінійним виразом (через наявні закони/`num`).
- Субтитри: `subtitles` з ASS-файлом і `fontsdir` (3.4). Шрифти — в образі API (`/app/packages/captions/fonts`).
- Задача `render` пише ASS з `renders.subtitles` у тимчасову теку.
- Нова точка входу `compileAudioOnly(doc, roles)` для мікса під STT.

## 9. Інтерфейс (apps/web)

### 9.1 `/voice` — список
Проєкти, що мають мови/сегменти (картка: мови з прапорцями стану), кнопка **«Озвучити відео»** → вибір з бібліотеки (відео) або перетягування файлу з ОС (завантаження → `voice.createFromAsset` після `ready`) → студія.

### 9.2 `/voice/$id` — студія
```
┌ назва · мови: [UK base][EN ✓][DE ⟳] [+ мова] · [Відкрити в редакторі] · [Рендер ▾]  ┐
├──────── прев'ю (мова ▾) ────────┤ сегменти                                         │
│ canvas + JASSUB, ▶, час          │ [Розпізнати мову оригіналу] [Вставити текст]      │
│                                  │ [Перекласти все] [Озвучити все ≈ $0.12]           │
├ смуга сегментів (межі тягнуться, │ ┌ 00:03–00:07 ▣ │ UK текст ✎ │ EN текст ✎ │ ▶ ↻ ● ┐ │
│ розрізати під плейхедом, злити)  │ │ …                                              │ │
├ оригінальний звук: Замінити /    │ стан рядка: порожній · у черзі · ● готово ·       │
│ Приглушити [25 %]                │ ● застарілий · ● помилка (текст, «Повторити»)     │
├ голос мови ▾ (модель, голос, ▶   │                                                  │
│ зразок, інструкції стилю)        │                                                  │
├ субтитри мови: увімк., стиль ▾,  │                                                  │
│ «Редагувати стиль» (панель)      │                                                  │
└──────────────────────────────────┴──────────────────────────────────────────────────┘
```
- Таблиця: базова мова + одна вибрана мова поруч (перемикач); редагування тексту на місці (збереження з debounce); ▶ — прослухати озвучку; ↻ — переозвучити; довжина: «база 4,1 с → EN 5,3 с (темп ×0,8 + стоп-кадр 0,2 с)».
- «Вставити текст» (німе відео): textarea → абзаци → `segmentsFromText` (рівномірно) або в наявні сегменти по порядку; далі межі тягнуться на смузі.
- Прев'ю мови X = `voice.localized` (оновлюється після кожної готової озвучки/зміни налаштувань); базова мова без озвучки = базовий документ.
- Рендер ▾: «Фінал 1080p / Чернетка 720p» × вибір мов (усі за замовчуванням) → `renders.startAll`; історія рендерів (наявний компонент) з мовою.
- Редактор стилю: поля з 3.1, живе прев'ю на поточному кадрі, «Зберегти як…» → `caption_styles`.

### 9.3 Редактор
- Перемикач над прев'ю: **«Монтаж»** (базовий документ, як зараз) / **мова X** (документ з `voice.localized`, таймлайн і прев'ю лише для перегляду з доріжками озвучки й субтитрів, банер «Перегляд мови EN — редагування в «Монтажі» або «Відокремити мову»»).
- Сегменти — смуга над лінійкою (межі тягнуться, S+⇧ — розрізати сегмент), лише в «Монтажі».
- Відокремлена мова — окремий пункт перемикача з позначкою; редагується повністю (зберігається в `project_language_timelines`), «Повернути до спільного» з підтвердженням.
- Кнопка «Озвучка» → `/voice/$id`. «Рендер ▾» отримує вибір мови.
- `PreviewEngine`: `speed` — `playbackRate` (з `preservesPitch`), `hold` — пауза на останньому кадрі; `envelope` — `GainNode.linearRampToValueAtTime`; JASSUB-шар (3.3).

### 9.4 Налаштування
Голос за замовчуванням для кожної мови (модель + голос + ▶ зразок); моделі TTS/STT вже вибираються в наявному блоці «за замовчуванням».

## 10. Помилки
| Ситуація | Поведінка |
|---|---|
| Немає ключа жодного TTS | моделі вимкнені «немає ключа»; кнопки озвучки неактивні з підказкою |
| Немає ключа OpenAI | мітки `estimated`, попередження в студії; розпізнавання — Gemini (лише сегменти) або недоступне |
| Помилка TTS / контент-політика | рядок `failed` з текстом помилки, «Повторити»; інші рядки не блокуються |
| Аудіо > 25 МБ для whisper | частини (4.2) |
| Сегмент > 1500 символів | `VALIDATION` «розділіть сегмент» |
| Рендер мови з неготовими рядками | `VALIDATION` з переліком; «Рендерити все одно» (неготові сегменти — без голосу, темп 1) |
| Видалено asset озвучки | рядок → `empty` (через `on delete set null`), позначка «озвучку видалено» |
| Мова без шрифтів для субтитрів | субтитри вимкнені з поясненням |
| JASSUB не завантажився | прев'ю без субтитрів + повідомлення; рендер працює |

## 11. Тестування
- **Unit:**
  - `localize`: сегмент довший/коротший/рівний, межі темпу (×0,8 + стоп-кадр; ×1,25 + обрізаний хвіст), сегмент без озвучки, проміжки між сегментами, кліп через межу сегмента (розрізання, перерахунок Ken Burns — закон у точках збігається з базовим ±1e-6), fade/xfade на межах, музика не розтягується, ducking-`envelope`, `replace`, доріжки озвучки/субтитрів, карта часу монотонна й узгоджена з кліпами, округлення до кадру;
  - `evaluate`/`audioPlan` зі `speed`/`hold`/`envelope`; операції сегментів; `segmentsFromSpeech`, `segmentsFromText`;
  - `alignWords` (пропущені/зайві/злиті слова, пунктуація, апострофи), `estimateWords`;
  - `layoutWords`, `toAss` (стилі, анімації, час слів відносно `in`), `toSrt/toVtt`;
  - `compileFfmpeg`: `setpts`/`tpad`/`atempo` на `original`, ніколи `atempo` на `voiceover`, `volume` з `eval=frame`, `subtitles` з `fontsdir`, `compileAudioOnly`.
- **Render** (ffmpeg у контейнері): тривалість мовної версії = `docDuration(localize(...))` ±1 кадр; стоп-кадр — кадри в зоні `hold` однакові; темп — кольорова мітка-лічильник у фікстурі з'являється в очікуваний момент; субтитри — у момент слова пікселі в зоні тексту не чорні, поза словами — чорні; ducking — RMS оригіналу під голосом нижчий на очікувану величину.
- **Інтеграційні** (FakeProvider): `voice.createFromAsset` → `voice.transcribe` (сегменти й рядки) → `voice.translate` → `voice.synthesize` (asset, транскрипт, `ready`, повтор не дублює) → `voice.localized` → `renders.start({ language })` → MP4 з тривалістю локалізованого документа; «застарілий» після зміни тексту/голосу; `separate`/`unseparate` і `projects.save` мови з конфліктом версії; ізоляція користувачів.
- **E2E** (Playwright, fake): «Озвучити відео» з ОС → розпізнати → додати EN → перекласти → озвучити все → прев'ю EN показує субтитри (непорожній JASSUB-canvas у момент слова) → рендер UK і EN → два MP4 у бібліотеці з різною тривалістю; німе відео: «Вставити текст» → 3 сегменти → озвучка → рендер; редактор: перемикач мови, банер перегляду, «Відокремити мову».
- **Live** (`pnpm test:live`): TTS обох провайдерів (WAV, тривалість > 0), `whisper-1` зі словами, Gemini STT сегменти.

## 12. Поза обсягом
ElevenLabs і клонування голосу; відділення голосу від музики (Demucs); озвучка діалогів кількома голосами; ручне редагування міток слів; субтитри для писемностей без вбудованих шрифтів, RTL; власні шрифти користувача; текстові титри; публікація субтитрів на платформи (підпроєкт 5); конвеєр «тема → чернетка» (підпроєкт 4, використає `voice.*`-сервіси й `localize`).

## 13. Готово, коли
- Готове відео з мовленням: «Озвучити відео» → розпізнати → 2+ мови → переклад → озвучка → субтитри зі стилем → рендер усіх мов; кожна мовна версія має власну тривалість, голос не прискорений, відео підігнане темпом/стоп-кадром, оригінал замінений або приглушений.
- Німе відео + текст → те саме без розпізнавання.
- Прев'ю мови в студії й редакторі збігається з рендером за тривалістю й таймінгом слів (±1 кадр); субтитри в прев'ю (JASSUB) і в MP4 (libass) з одного ASS.
- «Відокремити мову» дає незалежно редаговану мову.
- `pnpm test` (unit, int, render) і `pnpm --filter @vf/web e2e` проходять; `pnpm typecheck && pnpm lint` чисті.
