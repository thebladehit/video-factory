# Підпроєкт 4a «Редактор і голос: доопрацювання» — специфікація

- **Дата:** 2026-10-23
- **Статус:** погоджено в обговоренні, очікує перегляду
- **Базова специфікація:** `docs/specs/2026-10-20-video-factory-design.md`
- **Попередні підпроєкти:** 2 (редактор + рендер), 3 (озвучка, мови), 4 (конвеєр — `docs/specs/2026-10-20-subproject-4-pipeline.md`)
- **Гілка:** `feat/subproject-4a-editor-voice` від `main` (конвеєр уже в `main`, #5)

## 1. Мета

Чотири незалежні покращення, що з'явились після першого використання конвеєра:

1. **Розмір і позиція картинки** в кадрі — не лише ефект наближення.
2. **Озвучка одразу на таймлайні «Монтажу»** звичайними кліпами — бачити й чути відео з голосом під час монтажу.
3. **Панелі редактора зі зміною розміру** перетягуванням роздільників.
4. **Стабільний голос**: однакова подача в межах відео й між відео; вибір найкращих голосів UK/EN на слух.

### Рішення власника (з обговорення)
| Питання | Рішення |
|---|---|
| Розмір картинки | **Масштаб + позиція** (X/Y), рамка в прев'ю; фон — чорний. Обрізка (crop) і розмитий фон — не зараз |
| Озвучка в «Монтажі» | **Справжні кліпи** (рухати, різати, гучність, видаляти), а не доріжка лише для перегляду |
| Мовні версії | Базова мова = «Монтаж» як є (з правками голосу); інші мови — як зараз, без подвоєння голосу |
| Провайдер голосу | **Без нових провайдерів**: лише OpenAI і Gemini TTS |
| Фікс голосу | **A + B + C**: озвучка всього сценарію одним дублем із нарізкою; закріплена подача; порівняння голосів на слух |

Розділи 2–5 незалежні й реалізуються по черзі в цій гілці. Єдиний зв'язок: синхронізація з таймлайном (розділ 3) працює з дублями, створеними будь-яким способом — і окремим `voice.synthesize`, і пакетною озвучкою (4.3).

## 2. Розмір і позиція картинки

### 2.1 Модель
`MediaClip` (`packages/shared/src/timeline.ts`) отримує необов'язкове поле:
```ts
transform?: { scale: number; x: number; y: number }
// scale ∈ [0.1, 4] — множник до базового розміру fit (cover/contain); x, y ∈ [0, 1] — центр картинки в частках кадру
```
Відсутнє поле ≡ `{ scale: 1, x: 0.5, y: 0.5 }`. `normalizeDoc` не дописує поле (старі документи без змін); операції редактора пишуть його лише коли значення відрізняються від типових, а «Скинути» прибирає поле.

### 2.2 Геометрія (прев'ю = рендер)
Порядок: `fit` → `transform` → ефекти `zoom`/`kenburns` (вони діють навколо точки фокусу в межах уже зменшеної/зсунутої картинки).

- `coverRect` (`packages/timeline/src/draw.ts`) приймає `transform`: базовий прямокутник `fit` масштабується на `transform.scale` навколо свого центру й переноситься так, щоб центр був у `(x·W, y·H)`; далі — наявна формула масштабу ефекту навколо фокусу.
- `Layer` (`evaluate.ts`) несе `transform` кліпу.
- `transformFilter` (`packages/render/src/compile-video.ts`) отримує ту саму геометрію: `w0, h0, x0, y0` рахуються з урахуванням `transform` (статичні числа), вирази ефектів — без змін.
- Решта кадру — чорна (поточне полотно). Картинка може частково виходити за кадр.

### 2.3 UI
- **Інспектор кліпу (відео/фото):** група «Розмір і позиція»: повзунок «Розмір» 10–400 %, поля X / Y (%), кнопки «По центру» (x=y=0.5) і «Скинути».
- **Прев'ю:** для вибраного візуального кліпу під плейхедом — рамка з ручками в кутах поверх canvas (DOM-оверлей у координатах кадру). Перетягування рамки → позиція; кута → розмір із збереженням пропорцій. Під час жесту — живе оновлення, в історію (undo) — одна операція на жест. Під час відтворення та в режимі мови без відокремлення (лише перегляд) рамки немає.
- Операція документа `setClipTransform(clipId, transform | null)` у `packages/timeline/src/ops.ts` — через неї і інспектор, і рамка.

### 2.4 Тести
- Юніт: `coverRect` з `transform` (scale 0.5 по центру, зсув, комбінація з zoom); схема (межі, відсутнє поле); `setClipTransform`.
- Рендер: порівняння кадру `drawFrame` з кадром ffmpeg для `scale 0.5, x 0.3, y 0.7` (той самий метод, що для Ken Burns; поріг — як у наявних тестах).
- e2e: вибрати кліп → потягнути рамку → X/Y в інспекторі змінились → перезавантаження → значення ті самі.

## 3. Озвучка одразу на таймлайні «Монтажу»

### 3.1 Модель
У базовому документі — доріжка `audio`, `role: 'voiceover'`, `language: <базова мова>`, з кліпами по одному на сегмент. Кліп озвучки має `sceneId = segmentId` (як медіакліпи збірки) і `assetId` = аудіо готового дубля. Доріжка може мати поле
```ts
removedSegments?: string[]   // сегменти, кліп яких користувач видалив вручну
```
(лише для `role: 'voiceover'`), щоб синхронізація не повертала видалене.

### 3.2 Синхронізація — `syncVoiceTrack(doc, { language, takes })`
Чиста функція в `packages/timeline/src/voice-track.ts`. `takes` — готові й не застарілі дублі базової мови (`VoiceTake`: `segmentId`, `assetId`, `durationSec`, `transcriptId`). Правила для кожного сегмента документа:

| Стан | Дія |
|---|---|
| Дубль є, кліпу немає, сегмент не в `removedSegments` | вставити кліп: `start = segment.start + LEAD`, `in = 0`, `duration = durationSec` (на сітці кадрів), `volume = 1` |
| Дубль є, кліп є з іншим `assetId` | замінити `assetId`, `duration`, обнулити `in`; **зберегти** `start`, `volume`, `fadeIn/fadeOut`, `envelope` |
| Дубль є, кліп є з тим самим `assetId` | нічого |
| Дубля немає (рядок порожній/не готовий), кліп є | прибрати кліп |
| Сегмента більше немає | прибрати кліп і id з `removedSegments` |

Доріжки немає й дублів немає — документ без змін (проєкти без озвучки не отримують порожньої доріжки). Повертає новий документ і прапорець `changed`.

Видалення кліпу озвучки в редакторі (операція видалення кліпу) додає його `sceneId` у `removedSegments`; вставка дубля в цей сегмент з бібліотеки чи «Повернути озвучку сегмента» (контекстне меню сегмента) прибирає його звідти.

**Хто викликає:**
1. **`pipeline.assemble`** — після `assembleTimeline` (дублі вже готові, бо збірка йде після озвучки): чернетка одразу з голосом.
2. **Редактор** (`use-editor-assets`) — коли дані `voice.get` змінюються (новий дубль, очищений рядок) і документ відкритий у «Монтажі» не лише для читання: застосовує як звичайну операцію (з undo) й автозбереження. Пайплайн ще працює (документ заморожений) — не застосовує.
3. **Рендер «Монтажу»** (`render.start` без мови) — на копії документа перед компіляцією; базовий документ у БД не змінюється.

### 3.3 Мовні версії (`localize`)
- **Базова мова:** якщо в документі є доріжка озвучки базової мови, `localize` **не** підганяє сегменти (усі `speed 1`, `hold 0`), бере доріжку як є, будує субтитри з `audioClipId` кліпів цієї доріжки і `transcriptId` відповідних дублів, застосовує режим оригінального звуку (`replace`/`duck`) за кліпами доріжки. Доріжки немає — поведінка як зараз.
- **Інші мови:** перед побудовою доріжки озвучки інших мов (`language ≠` цільової) прибираються; далі — як зараз.
- Відокремлені мови не змінюються.

### 3.4 Межі
- Дубль довший за сегмент: кліп заходить на наступний сегмент; на таймлайні кліп підсвічується попередженням із підказкою «Озвучка довша за сцену на N с». Автоматичного зсуву наступних сцен (ripple) немає — поза межами.
- Старі проєкти з готовими дублями й без доріжки отримують її при першому відкритті «Монтажу» (виклик 2).
- Перевірка готовності при рендері базової мови (діалог «неозвучені сегменти») лишається без змін.

### 3.5 Тести
- Юніт `syncVoiceTrack`: вставка; заміна зі збереженням `start/volume/fade`; `removedSegments`; очищений рядок; видалений сегмент; без дублів і без доріжки — без змін.
- Юніт `localize`: база з доріжкою = документ без підгонки + субтитри; інша мова — доріжка бази прибрана, голос не подвоєний.
- Інтеграційний: конвеєр → `projects.timeline` містить доріжку озвучки з кліпами всіх сцен.
- e2e: озвучити рядок у студії → у «Монтажі» з'явився кліп → видалити його → після оновлення дублів не повертається.

## 4. Стабільний голос

### 4.1 Проблема
OpenAI `gpt-4o-mini-tts` і Gemini TTS — генеративні: інтонація, темп і емоція відрізняються між запитами; seed немає. Зараз кожен рядок — окремий запит без зафіксованої подачі, тож голос «гуляє» і в межах відео, і між відео.

### 4.2 B — закріплена подача
- `packages/ai`: типові інструкції подачі для мов (`DEFAULT_DELIVERY: Record<string, string>` з запасним англійським текстом для решти мов), напр. для `uk`: «Рівний спокійний оповідач, помірний темп, нейтральна інтонація, без драматизму й шепоту, однакова гучність». `voiceForLanguage` повертає `instructions ?? DEFAULT_DELIVERY[lang]`. **`voicedHash` не змінюється** для голосів з уже заданою інструкцією; для голосів без неї типова інструкція стає частиною хешу — їхні рядки стануть застарілими (очікувано: переозвучка дасть стабільний голос).
- `VoicePicker`: поле інструкції показує типову як плейсхолдер і кнопку «Вставити типову».
- `google-speech.ts`: `generationConfig.temperature = GEMINI_TTS_TEMPERATURE` (константа, стартове значення `0.4`; уточнюється за результатами 4.4).

### 4.3 A — озвучка сценарію одним дублем
Нова задача **`voice.synthesizeBatch`** `{ projectId, language, lineIds }`:
1. Захоплює рядки так само атомарно, як `voice.synthesize` (статус `running`, `job_id`); знімок тексту й голосу на старті.
2. Ділить рядки на шматки в порядку сегментів: шматок ≤ `TTS_MAX_CHARS` (1500), лише по межах рядків; рядок довший за ліміт — окремий шматок (як зараз).
3. Текст шматка — рядки через порожній рядок (абзаци → природна пауза). Один запит TTS на шматок з тим самим голосом та інструкцією.
4. Мітки слів шматка: від TTS, якщо є; інакше whisper + `alignWords` (наявний `wordTimings`).
5. **Межі рядків** (`packages/captions/src/split.ts`, чиста функція `splitTake(words, lineTexts, speech)`): для кожної пари сусідніх рядків — пауза між кінцем останнього слова рядка `i` і початком першого слова рядка `i+1`; межа — середина паузи, прив'язана до найближчого інтервалу тиші з `speechIntervals`. Межа **ненадійна**, якщо будь-яке з двох слів не вирівняне (`alignWords` без відповідника) або пауза < 80 мс.
6. Кожен рядок із надійними межами → вирізка wav (ffmpeg `atrim`) → asset `audio` → транскрипт зі словами, зсунутими на початок вирізки → рядок `ready` з `voiced_hash` (той самий, що дав би `voice.synthesize`).
7. Рядки з ненадійною межею → ставляться окремими `voice.synthesize` (фолбек); рядки шматка з помилкою TTS → `failed` як зараз.
8. Генерація пишеться одна на шматок (`generations`, `capability: 'tts'`, `params.lineIds`); вартість розподіляється пропорційно довжині вирізок лише для показу.

**Хто ставить:** `enqueueSynthesize` — коли для мови ≥ 2 рядків, ставить одну `voice.synthesizeBatch` на мову замість окремих задач. Його викликають і конвеєр, і «Озвучити все» у студії. Перегенерація одного рядка — як зараз, окремий `voice.synthesize`. Скасування — як для наявних задач (рядки повертаються в попередній стан).

### 4.4 C — «Порівняти голоси»
- **Де:** кнопка «Порівняти голоси» в налаштуваннях голосів за замовчуванням (`DefaultVoices`) для кожної мови.
- **Діалог:** мова; фраза-зразок (типова для UK/EN ~2 речення, можна змінити, ≤ 300 символів); кандидати з чекбоксами (типово: OpenAI `marin`, `cedar`, `ash`, `coral`; Gemini 3.8 Flash TTS `Autonoe`, `Vindemiatrix`, `Kore`, `Charon` — лише доступні з ключем); інструкція подачі (типова з 4.2). Перед запуском — оцінка вартості.
- **Генерація:** кожен кандидат × **2 дублі** (видно стабільність). Розширення наявного `previewVoice` → мутація `voice.audition { model, voiceId, language, text, instructions, take }`: синхронний запит TTS, файл у сховищі `u/<user>/voice-samples/audition/<sha256(model|voice|lang|text|instructions)>/<take>.wav` (повторне відкриття не платить вдруге), повертає підписаний URL. Без asset'ів і без запису в історію генерацій (як зразок голосу зараз). Клієнт запускає кандидатів паралельно, не більше 3 одночасно.
- **Результат:** таблиця кандидат × дубль із ▶, кнопка «Зробити типовим» (зберігає модель, голос та інструкцію в голос за замовчуванням мови).
- Усі стартові кандидати вже є в каталозі (`Vindemiatrix` теж).

### 4.5 Тести
- Юніт: поділ на шматки (межі рядків, ліміт); `splitTake` на синтетичних мітках (надійні межі, нерозпізнане слово, коротка пауза → ненадійна); типова інструкція й `voicedHash`; `temperature` у тілі запиту Gemini.
- Інтеграційний (fake TTS, що повертає мітки слів): `voice.synthesizeBatch` на 4 рядки → 4 asset'и, тривалості в сумі ≈ дубль, транскрипти зсунуті; рядок із ненадійною межею → поставлено `voice.synthesize`.
- e2e: діалог порівняння на fake TTS → 2 дублі на кандидата → «Зробити типовим» → голос за замовчуванням змінився.

## 5. Панелі редактора зі зміною розміру

- Примітив shadcn **Resizable** (`react-resizable-panels`) → `apps/web/src/components/ui/resizable.tsx`.
- **Горизонтально:** Бібліотека | Прев'ю | Інспектор. **Вертикально:** верхня зона | Таймлайн (смуга сегментів — разом із таймлайном).
- Мінімуми: бібліотека 160 px, інспектор 220 px, прев'ю й таймлайн 120 px; бібліотеку й інспектор можна згорнути перетягуванням до краю (collapsible) і розгорнути назад.
- Подвійний клік по роздільнику — типовий розмір. Розміри — в `localStorage` (`autoSaveId`), читання/запис у try/catch; без сховища — типова розкладка.
- Банери (конвеєр, мова), тулбар та історія рендерів — поза панелями.
- Тест e2e: потягнути роздільник бібліотеки → ширина змінилась → перезавантаження → ширина та сама.

## 6. Поза межами
- Обрізка (crop), обертання, розмитий фон для зменшеної картинки.
- Редагування голосу іншими мовами як звичайних кліпів без відокремлення мови.
- Нові TTS-провайдери (ElevenLabs, Google Cloud TTS).
- Автоматична оцінка «найкращого» голосу (метрики) — вибір лише на слух у 4.4.
