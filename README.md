## Передумови

- Docker Desktop (запущений)
- Node.js ≥ 24
- pnpm 12: `npm i -g pnpm@12`

## Швидкий старт

```bash
cp .env.example .env
docker compose up -d --build   # Postgres, RustFS і API (з ffmpeg); міграції застосовуються автоматично
pnpm install                   # залежності для web на хості
pnpm dev                       # web (Vite) на хості
```

Відкрийте http://localhost:5173 → «Налаштування».

- API працює в контейнері `api` (http://localhost:3001, tRPC на `/trpc`): сирці змонтовані, зміни підхоплюються без перезбирання. Логи — `docker compose logs -f api`. Після зміни `pnpm-lock.yaml` залежності в контейнері оновлюються самі при наступному старті (`docker compose restart api`).
- Консоль сховища RustFS: http://localhost:9001 (логін і пароль — `S3_ACCESS_KEY_ID` / `S3_SECRET_ACCESS_KEY` з `.env`)

## AI-ключі

Впишіть у `.env` ключі провайдерів, якими користуєтесь (порожньо = провайдер недоступний), і перезапустіть `pnpm dev`:

```
ANTHROPIC_API_KEY=...
OPENAI_API_KEY=...
GOOGLE_API_KEY=...   # лише платний ключ Gemini
```

`AI_FAKE=1` вмикає fake-провайдер: детерміновані відповіді без витрат, щоб працювати з UI без ключів.

## Бібліотека

- **Завантаження:** перетягніть файли на будь-яку сторінку або натисніть «Завантажити» в «Бібліотеці». Файли йдуть напряму в сховище (великі — частинами по 16 МБ), потім API читає метадані (ffprobe) і робить мініатюру.
  - Фото: JPEG, PNG, WebP, GIF — до 50 МБ; відео: MP4, MOV, WebM — до 5 ГБ; аудіо: MP3, WAV, M4A, OGG — до 500 МБ.
- **Генерація:** «Згенерувати» → фото або відео з текстового опису; модель вибирається для кожного запуску (за замовчуванням — з «Налаштувань»). Вартість кожного виклику пишеться в `generations.cost_estimate`.
  - Фото: OpenAI GPT Image, Google Gemini Image. Відео: Google Gemini Omni Flash (OpenAI Sora API вимкнено у вересні 2026, Veo preview у Gemini API — у жовтні 2026).
- **Теги й пошук:** згенеровані файли отримують теги з опису; завантажені — з мініатюри (vision), якщо в «Налаштуваннях» увімкнено «Авто-теги» (≈ $0.0001–0.0003 за файл на дешевій моделі). Пошук — за назвою, тегами й описом, зокрема з опечатками; фільтри — тип, джерело, орієнтація, теги.
- Файли видно в консолі RustFS (http://localhost:9001), бакет `vf-media`, ключі `u/<користувач>/assets/<id>/…`. Незавершені завантаження прибираються через 24 год.

## Редактор і рендер

- **Проєкти** — головна сторінка (`/`): сітка проєктів, «Новий проєкт» (назва, 9:16 або 16:9), меню картки — перейменувати, дублювати, видалити (готові рендери лишаються в бібліотеці).
- **Редактор** (`/projects/<id>`): зліва бібліотека (пошук, фільтр типу; перетягніть файл на таймлайн або «+» — під плейхед), у центрі canvas-прев'ю, справа інспектор кліпу, знизу таймлайн і історія рендерів.
  - Файли можна кидати й прямо з комп'ютера на таймлайн: кліп з'являється одразу, файл паралельно вантажиться в бібліотеку; рендер доступний, коли файл оброблено.
  - Відео зі звуком отримує зв'язаний кліп на доріжці «Звук відео» з хвилею: його можна видалити, змінити гучність 0–200 % або «Від'єднати звук».
  - Фото автоматично отримує Ken Burns (1 → 1,15); ефекти Ken Burns, Zoom, поява/зникнення й перехід (перекриття з попереднім кліпом — ручка-ромб на стику або повзунок) налаштовуються в інспекторі.
  - **Розмір і позиція** картинки (відео/фото): в інспекторі — «Розмір» 10–400 %, X / Y центру в % кадру, «По центру», «Скинути»; у прев'ю — рамка вибраного кліпу (тягнути — позиція, кут — розмір із пропорціями, жест — один крок undo). Решта кадру чорна, картинка може виходити за кадр. Ефекти Zoom і Ken Burns діють уже в межах зменшеної/зсунутої картинки; рендер дає той самий кадр, що й прев'ю.
  - **Панелі** бібліотеки, прев'ю, інспектора й таймлайну змінюють розмір перетягуванням роздільників (мінімуми: бібліотека 160 px, інспектор 220 px, прев'ю й таймлайн 120 px); бібліотеку й інспектор можна згорнути до краю, подвійний клік по роздільнику — типовий розмір. Розкладка запам'ятовується в браузері.
  - Таймлайн: рух (зокрема між відео-доріжками), трім за краї, снепінг до країв кліпів і плейхеда (8 px), зум — Ctrl/⌘ + колесо або повзунок, клік по лінійці — перемотка. Усі часи — кадри 1/30 с.
  - Клавіші: **S** — розрізати під плейхедом, **Del/Backspace** — видалити, **Space** — відтворення, **⌘Z / ⇧⌘Z** — скасувати/повторити (жест — один крок, до 100 кроків), **← / →** — кадр, **⇧← / ⇧→** — 1 с.
  - Автозбереження через 1,5 с після змін; якщо проєкт змінили в іншій вкладці — вибір «Перезавантажити» або «Перезаписати моєю версією».
- **Рендер** — «Рендер ▾» → «Фінал 1080p» або «Чернетка 720p» (H.264 + AAC, 30 кадр/с). Прогрес і скасування — в «Історії рендерів»; готовий MP4 з'являється в бібліотеці (джерело «rendered», назва «{проєкт} — {дата час}») з посиланнями «Завантажити» і «Відкрити в бібліотеці».
- Видалення файлу, який стоїть у проєктах, попереджає зі списком проєктів; на таймлайні лишається червона заглушка «файл видалено», рендер недоступний, доки її не замінити.
- Прев'ю й рендер рахують кадр з одного опису (`packages/timeline`): прев'ю — canvas + Web Audio, рендер — граф ffmpeg (`packages/render`, без `zoompan`; Ken Burns композиться у 2× для плавності).

## Озвучка й субтитри

- **Студія** (`/voice`, `/voice/<id>`): «Озвучити відео» → відео з бібліотеки або файл з ОС → проєкт зі сегментами. Два сценарії:
  - **дубляж** (відео з мовленням): «Розпізнати мову оригіналу» → сегменти й тексти базової мови → «+ мова» → «Перекласти все» → «Озвучити все» (перед запуском видно оцінку вартості);
  - **німе відео**: «Вставити текст» (абзаци → сегменти) → переклад → озвучка.
- **Довжина мови.** Відео підлаштовується під озвучку, а не навпаки: голос ніколи не прискорюється. Шматок відео сегмента змінює темп у межах ×0,8…×1,25; якщо озвучки все одно більше — стоп-кадр у кінці, якщо менше — хвіст обрізається. Кожна мовна версія має власну тривалість; прев'ю й рендер рахують її однією функцією `localize` (`packages/timeline`).
- **Оригінальний звук:** «Замінити» або «Приглушити» (рівень 25 %, під голосом — 8 %, з плавними переходами).
- **Субтитри:** 4 пресети (shorts, pop, karaoke, classic) і редактор стилю (6 вбудованих шрифтів: Montserrat, Inter, Oswald, Rubik, Roboto Slab, Unbounded; зберігаються стилі). У прев'ю — JASSUB, у MP4 — libass, обидва з одного ASS; є вивантаження `.srt` / `.vtt`.
- **Редактор:** перемикач «Монтаж» / мова X (перегляд з доріжками озвучки й субтитрів, лише читання), «Відокремити мову» (мова стає окремим документом, що редагується повністю; «Повернути до спільного»), «Рендер ▾» з вибором мов. У студії «Рендер ▾» ставить рендер кожної вибраної мови окремим MP4 у бібліотеку.
- **Озвучка в «Монтажі».** Готові дублі базової мови одразу лежать на таймлайні звичайними кліпами доріжки озвучки (один кліп на сегмент, старт — початок сегмента + 0,15 с): їх можна рухати, різати, міняти гучність і видаляти. Новий дубль рядка замінює файл кліпу, зберігаючи його позицію, гучність і згасання; очищений рядок прибирає кліп; видалений вручну кліп після переозвучки не повертається — «Повернути озвучку» в меню сегмента. Дубль, довший за сцену, підсвічується підказкою «Озвучка довша за сцену на N с» (наступні сцени не зсуваються). Синхронізація — звичайний крок історії (undo) з автозбереженням; старі проєкти отримують доріжку при першому відкритті «Монтажу». Рендер «Монтажу» й базової мови бере цю доріжку як є (без підгонки темпу); інші мови — як раніше, без подвоєння голосу.
- **Стабільний голос.**
  - Закріплена подача: голос без власної інструкції отримує типову для мови (UK/EN — рівний спокійний оповідач, помірний темп); у виборі голосу вона видна як підказка, «Вставити типову» — вписати її. Gemini TTS працює з температурою 0,4. Рядки голосів без інструкції після оновлення стали застарілими — переозвучка дасть стабільніший голос.
  - Озвучка сценарію одним дублем: «Озвучити все» і конвеєр для мови з ≥ 2 рядків ставлять одну задачу, що озвучує текст шматками до 1500 символів (рядки — абзацами) і ріже дубль на рядки по паузах за мітками слів. Межа, де слово не розпізнане чи пауза < 80 мс, ненадійна — такий рядок озвучується окремим запитом. Перегенерація одного рядка — як раніше, окремо.
  - «Порівняти голоси» (Налаштування → голоси за замовчуванням, для кожної мови): фраза-зразок (≤ 300 символів), кандидати OpenAI і Gemini (лише з ключем), інструкція подачі, оцінка вартості; кожен кандидат — 2 дублі, щоб почути стабільність (≤ 3 запити одночасно, повторне відкриття не платить вдруге). «Зробити типовим» зберігає модель, голос та інструкцію для мови.
- **Ключі й моделі** (`.env` або «Налаштування»): озвучка — `OPENAI_API_KEY` (gpt-4o-mini-tts) або `GOOGLE_API_KEY` (Gemini TTS); розпізнавання — OpenAI `whisper-1` (дає мітки слів) або Gemini (лише фрази); переклад — будь-яка текстова модель (Anthropic, OpenAI, Google). Без ключа OpenAI мітки слів оцінюються за довжиною слів і паузами (у студії є попередження); без ключа TTS кнопки озвучки неактивні з підказкою. `AI_FAKE=1` — fake-провайдер без витрат (тиша замість голосу, переклад `[en] …`).
- **Вартість (оцінка):** озвучка ≈ $0,009–0,015 за хвилину аудіо, `whisper-1` — $0,006/хв, переклад — копійки. Оцінка в студії рахує ≈ 15 символів на секунду.
- **Обмеження:** текст рядка — до 1500 символів (довше — розділіть сегмент); субтитри лише для мов із вбудованим шрифтом (інакше вимкнені з поясненням); розпізнавання аудіо довше 90 хв йде частинами по 60 хв (перекриття 5 с); один голос на мову (без діалогів і клонування); відділення голосу від музики немає. Шрифти субтитрів для рендеру — `packages/captions/fonts` (інший каталог — `CAPTIONS_FONTS_DIR`).

## Відео з теми

- **Кроки:** головна (`/`) → «Відео з теми» → тема (3–2000 символів), формат (9:16 — 15–90 с, за замовчуванням 45; 16:9 — 1–15 хв, за замовчуванням 5), стиль (необов'язково), мови (чіпи) і голос кожної мови, моделі тексту й фото, музика з бібліотеки або без неї → «Створити». Унизу діалогу — оцінка вартості; якщо кнопка неактивна, причина написана під оцінкою (немає ключа, не вибрано голос).
- **Сторінка сцен** (`/projects/<id>/pipeline`): етапи «Сценарій → Перевірка → Візуал і озвучка N/M → Збірка → Готово» з живим прогресом. Сцена = сегмент озвучки: текст базової мови, промпт фото, ключові слова, мініатюра візуалу, стан озвучки кожної мови (клік — студія).
  - Візуал сцени: файл із бібліотеки, якщо збіг за ключовими словами сильний (один файл — не більше однієї сцени, орієнтація формату або квадрат), інакше — згенероване фото; слабкі збіги показуються як підказки. Будь-яку сцену можна перегенерувати (текст ↻, фото ↻, відео 🎬, вибір з бібліотеки 📚) і після збірки — кліп у таймлайні змінюється точково. «Пересібрати» збирає документ наново з підтвердженням.
  - ☐ «Зупинитися після сценарію» (для 16:9 увімкнено за замовчуванням): після сценарію запуск чекає на етапі «Перевірка» — тексти, промпти й порядок сцен правляться, сцени додаються й видаляються до дорогих кроків; «Продовжити» запускає візуал і озвучку.
- **Результат:** чернетка в редакторі (автоперехід, щойно збірку завершено, якщо сторінка сцен відкрита): прямі склейки, фото з Ken Burns, відео сцени повторюється, якщо коротше за озвучку, базова мова озвучена з темпом ×1 (голос — кліпами доріжки озвучки прямо в «Монтажі»), мовні версії — з перекладом, озвучкою й субтитрами (9:16 — пресет shorts, 16:9 — classic), опційна музика (15 %, згасання в кінці). Далі — звичайний «Рендер ▾» з вибором мови. Поки конвеєр працює, редактор лише для перегляду (банер і кнопка «Сцени»).
- **Переклад мов:** використовує типову модель тексту з налаштувань (задача перекладу студії озвучки), а не модель тексту з діалогу.
- **Ключі:** модель тексту — `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` або `GOOGLE_API_KEY`; фото — `OPENAI_API_KEY` (GPT Image) або `GOOGLE_API_KEY` (Gemini Image); озвучка — як у студії (`OPENAI_API_KEY` або `GOOGLE_API_KEY`), мітки слів для субтитрів — `whisper-1` (OpenAI). Відео сцени (🎬) — `GOOGLE_API_KEY`. `AI_FAKE=1` — увесь конвеєр без витрат (сценарій «Сцена N. …», однотонні фото, тиша замість голосу).
- **Вартість (оцінка, верхня межа — кожна сцена генерує фото):** основну частину дає фото (≈ $0,011–0,067 за сцену). Shorts 45 с, uk + en, Claude Sonnet + GPT Image 2 + gpt-4o-mini-tts — ≈ $0,41 (9 фото ≈ $0,36, озвучка й мітки ≈ $0,03, сценарій і переклад ≈ $0,02); з GPT Image 1 mini — ≈ $0,14. Відео 16:9 на 5 хв однією мовою — ≈ $0,95 (20 сцен). Сцени з бібліотеки фото не генерують; відео сцени (🎬) рахується окремо (≈ $0,10/с).
- **Помилки:**
  - сценарій: невалідна відповідь моделі — одна повторна спроба, далі запуск «Конвеєр: помилка» з текстом і кнопкою «Повторити»; відмова за контент-політикою чи ліміт провайдера — без повтору;
  - помилка фото сцени чи озвучки рядка не зупиняє запуск: сцена позначається помилкою (у таймлайні — чорна заглушка «Порожня сцена»), сцена без озвучки отримує оцінену тривалість; повторити можна на сцені або в студії. Якщо базова озвучка не вдалася зовсім — банер «Озвучка не вдалася — повторіть у студії»;
  - «Скасувати» зупиняє задачі запуску; «Повторити» продовжує з того самого етапу без дублювання сцен. Рестарт API посеред запуску не губить його: незавершений етап стає помилкою з «Повторити»;
  - «Пересібрати» після змін у редакторі в іншій вкладці — «Таймлайн змінено — оновіть сторінку».

## Публікація

- **Сторінка «Публікації»** (`/publications`): угорі акаунти (YouTube через API або будь-яка платформа вручну; кожен акаунт має мову — відео цієї мови пропонуються на нього), нижче матриця «мовна версія × платформа» зі статусами. «Опублікувати…» — тут або в «Історії рендерів» біля готового фінального рендеру: вибір мовних версій і акаунтів, метадані від AI (типова модель тексту з «Налаштувань»; поля можна правити, ліміти платформ перевіряються), «Зараз» або дата й час.
- **YouTube (API):** завантаження частинами по 8 МіБ продовжується після рестарту API; далі тік (раз на хвилину) чекає завершення обробки на YouTube — комірка «Опубліковано» з посиланням. Запланований час передається YouTube (`publishAt`), відео завантажується одразу.
- **Вручну (TikTok, Instagram, Facebook, YouTube без API):** у потрібний час комірка стає «Чекає на вас» (лічильник у меню біля «Публікації»): «Завантажити MP4», «Скопіювати метадані», опублікувати самому й «Вставити посилання» — посилання перевіряється на відповідність платформі.

### Налаштування Google Cloud (один раз)

1. https://console.cloud.google.com → новий проєкт → «APIs & Services» → «Library» → увімкнути **YouTube Data API v3**.
2. «OAuth consent screen»: тип **External**, свою Google-адресу додати в **Test users**.
3. «Credentials» → «Create credentials» → «OAuth client ID» → тип **Web application**, Authorized redirect URI: `http://localhost:5173/oauth/youtube/callback` (інший `WEB_ORIGIN` — `${WEB_ORIGIN}/oauth/youtube/callback`).
4. Client ID і Client secret — у `.env` (значення нікуди не комітьте), перезапустіть `pnpm dev`:

```
YOUTUBE_CLIENT_ID=...apps.googleusercontent.com
YOUTUBE_CLIENT_SECRET=...
TOKEN_ENCRYPTION_KEY=...   # openssl rand -base64 32 — шифрує токени в БД; обов'язковий, якщо задано YOUTUBE_CLIENT_ID
YOUTUBE_API_AUDITED=0      # 1 — після аудиту YouTube API (прибирає підказку про приватні відео)
PUBLISH_FAKE=              # 1 — fake OAuth і публікатор замість Google (розробка без ключів, e2e)
PUBLISH_TICK_MS=           # період тіку публікацій, мс; порожньо = 60000 (e2e — 2000)
```

Далі «Публікації» → «Підключити YouTube» → мова каналу → згода Google → тост «Канал підключено». Без `YOUTUBE_CLIENT_ID` кнопка вимкнена, ручна публікація працює. Зміна `TOKEN_ENCRYPTION_KEY` робить збережені токени нечитабельними — канали доведеться перепідключити.

### Обмеження

- **Аудит YouTube API:** поки Google-проєкт не пройшов аудит (форма «YouTube API Services — Audit and Quota Extension»), YouTube робить відео, завантажені через API, **приватними** — їх видно лише в YouTube Studio. Подайте форму, коли потік запрацює, і після схвалення поставте `YOUTUBE_API_AUDITED=1`.
- **Режим Testing:** поки OAuth-застосунок у статусі «Testing», refresh-токени Google спливають **через 7 днів** — акаунт стає «Потрібно перепідключити» (кнопка «Перепідключити» на картці). Щоб цього уникнути, переведіть застосунок у «In production» (OAuth consent screen → «Publish app»).
- TikTok, Instagram і Facebook поки лише вручну (API-адаптери — окремий підпроєкт).

## Тести

```bash
pnpm test                    # unit + інтеграційні — у контейнері api (там ffmpeg), потрібен docker compose up -d
pnpm test:unit               # лише unit
pnpm test:live               # справжні виклики AI-провайдерів з ключами з .env
pnpm --filter @vf/web e2e    # Playwright на хості; API — контейнер api-e2e (тестова БД, порт 3101)
pnpm typecheck && pnpm lint
```

Будь-яку vitest-команду можна виконати в контейнері так: `docker compose run --rm api pnpm vt <фільтр>`.

Перед першим e2e: `pnpm --filter @vf/web exec playwright install chromium`.

## Примітки

- **Новий пакет у `packages/`** → додайте рядок тому `node_modules` у `volumes` сервісу `api` (і в список томів унизу) у `docker-compose.yml` (інакше в контейнері його залежності змішаються з macOS-версіями з хоста).

- **S3 локально — RustFS**, не MinIO: MinIO з жовтня 2025 не публікує Docker-образи. Запасний варіант — SeaweedFS (`weed server -s3`), бо код працює через інтерфейс `BlobStorage`.
- Черга задач зараз виконується в процесі API, а її стан зберігається в Postgres. Після перезапуску незавершені задачі позначаються «Перервано перезапуском сервера», а ті, що чекали в черзі, виконуються.
